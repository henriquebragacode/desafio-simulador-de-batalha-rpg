# ⚔️ Simulador de Batalha RPG

## 📝 Sobre o Projeto
Este é um programa de terminal que simula uma batalha automatizada em turnos entre o herói **Hércules** e o monstro **Minotauro**. A batalha acontece de forma dinâmica e inteligente, rodando até que a vida de um dos personagens chegue a zero, exibindo o vencedor no final.

## 🚀 Conceitos de Programação Aplicados
Neste projeto, coloquei em prática meus conhecimentos da primeira semana de estudos na **DIO**, utilizando:
- **Variáveis e Operadores:** Controle de pontos de vida, dano e contagem de turnos (`let`, `-=`, `++`).
- **Estruturas de Repetição:** Uso do laço `while` para manter a batalha rodando enquanto ambos estiverem vivos.
- **Estruturas Condicionais:** Uso de `if` para garantir que o monstro não contra-ataque se já tiver sido derrotado no mesmo turno.
- **Estruturas de Decisão:** Uso do `switch (true)` para verificar de forma elegante quem foi o vencedor da batalha.
- **Template Strings:** Uso moderno de crases (\`\`) para exibir as mensagens do terminal de forma limpa.

## 🛠️ Tecnologias Utilizadas
